# Snake Eating Chicken!

Barnvænn Snake-leikur á íslensku. Leikurinn er sjálfstæð PWA-vefsíða og þarf hvorki innskráningu né net eftir fyrstu opnun.

## Stýring

- Örvatakkar eða WASD
- Strjúka eða nota snertitakka á síma/spjaldtölvu
- P eða Escape gerir hlé
- F kveikir á fullscreen
- M kveikir/slökkvir á hljóði

## Uppsetning sem app

Opnaðu GitHub Pages-slóðina í Chrome eða Edge og ýttu á **Setja upp appið**. Þegar leikurinn er opnaður sem uppsett app notar hann fullscreen.

## Keyra staðbundið

```bash
python -m http.server 8000
```

Opnaðu síðan `http://localhost:8000`.

## Hljóðleyfi

Leikjahljóð eru úr CC0-pökkum Kenney. Náttúrulegu hænu- og hanahljóðin eru úr almenningseign. Sjá `AUDIO_LICENSES.md`.
